# 📄 AI Resume Reviewer

An AI-powered Resume Reviewer built with **Python**, **Streamlit**, and **Google Gemini AI**. The application analyzes a user's resume against a target job role and provides an ATS-style review with actionable feedback.

---

## 🚀 Features

- 📄 Upload resume in PDF format
- 💼 Enter the target job role
- 🤖 AI-powered resume analysis
- 📊 ATS-style resume score
- ✅ Strengths and weaknesses
- 🛠️ Missing skills identification
- 💡 Personalized improvement suggestions
- ⚡ Simple and user-friendly Streamlit interface

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- python-dotenv
- PyPDF

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/AI-Resume-Reviewer.git
```

Move into the project folder:

```bash
cd AI-Resume-Reviewer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the project folder.

```text
GEMINI_API_KEY=your_api_key_here
```

> **Note:** Never upload your `.env` file to GitHub.

---

## ▶️ Run the Application

```bash
streamlit run ResumeApp.py
```

## 📸 Demo
